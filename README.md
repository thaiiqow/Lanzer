# Lanzer — Neon Liquid Glass start page

Футуристичная адаптивная стартовая страница в стиле Liquid Glass с красно-чёрной неоновой темой и переключателем цветовых схем. Работает на компьютерах и телефонах.

## Возможности
- Поиск через Google, DuckDuckGo или Bing.
- Переход на готовые популярные сайты.
- Добавление своих ссылок с названием и эмодзи.
- Удаление пользовательских ссылок.
- Красно-чёрная, чёрно-белая, чёрно-голубая, фиолетовая, зелёная, розовая и оранжевая неоновые темы; также светлая тема.
- Часы и дата.
- Сохранение пользовательских сайтов в `localStorage` текущего браузера.
- Без сборки и дополнительных зависимостей.

## Запуск локально
Открой `index.html` в браузере.

## Публикация на GitHub Pages
1. Создай новый публичный репозиторий на GitHub, например `lanzer-browser`.
2. Загрузи в корень репозитория файлы `index.html`, `style.css`, `script.js` и `README.md`.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`, нажми **Save**.
6. Подожди завершения публикации. GitHub покажет адрес сайта в разделе Pages.

## Важно
Это не полноценный браузерный движок: сайты открываются в новой вкладке обычного браузера, потому что браузеры не позволяют веб-странице безопасно встраивать любые сайты внутрь себя. Добавленные ссылки хранятся отдельно в каждом браузере/устройстве и не синхронизируются автоматически.
